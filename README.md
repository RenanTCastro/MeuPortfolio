# Portfólio — Renan Castro

Meu site pessoal de portfólio. Reúne stack, projetos selecionados, experiência profissional e formação em uma única página.

## Seções

- **Hero:** apresentação, links para GitHub e LinkedIn e principais tecnologias
- **Sobre:** resumo da atuação profissional
- **Stack:** frontend, backend, banco de dados e ferramentas
- **Projetos:** YTRIO, Negocia+ e Portal B2B (case privado), Pão na Conta e Monitoramento de Segurança Industrial (TCC)
- **Experiência e formação:** Grupo SOMA, FARMly, CPE, Impacta e UFMG
- **Contato:** LinkedIn, GitHub e email

## Tecnologias

- HTML5
- CSS3 (Grid, Flexbox, variáveis CSS e media queries)
- JavaScript puro (animações de entrada com `IntersectionObserver`)

Não usa framework nem etapa de build: a página inteira está em um único `index.html`.

## Estrutura

```text
.
├── index.html          # página completa (HTML, CSS e JS)
├── favicon.svg
├── profile.png         # foto do hero
├── paonaconta.mp4      # demonstração do Pão na Conta
├── pfc-dashboard.png   # dashboard do TCC
└── README.md
```

## Como rodar

Abra o `index.html` direto no navegador. Os arquivos de imagem e vídeo precisam estar na mesma pasta.
